# RED LEDGER（赤帳）

## 一句話

配給帳冊當機後，真短缺在北里；幽靈戶籍把南里畫成災區。錯發公共勸告會加劇動亂。

## 與其他場景的差異（六軸）

| 軸 | RED LEDGER |
|---|---|
| 依賴圖 | `ration_halt`(water) → `shelter_blackout`(power) → `clinic_overflow`(medical) |
| 觀察通道 | 自動化 census feed + 新聞勸離，假「幽靈受益戶」 |
| 資源取捨 | **較多勸告次數**（誘使誤發）+ 有限發電機給庇護所 |
| 失敗連鎖 | 物流停滯 → 庇護所停電 → 診所爆量 |
| 穩健策略 | 先驗證戶籍主張，修配給場供水，發電機護北里，醫療預置診所 |
| 校準難題 | 南里「該撤離」與北里「已無救」的假報同時出現 |

## 不要做的事

- 依 census / 新聞對 **South Wards** 發撤離勸告  
- 把兩台發電機都丟去南里  
- 忽略 Ration Yard 的供水修復
