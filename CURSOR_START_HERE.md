1. Open this `null-city` folder in Cursor.
2. Read `README_FIRST.md`.
3. Open Cursor Plan Mode.
4. Paste the full contents of `04_CURSOR_KICKOFF_PROMPT.md`.
5. Authorize **M0 only**.
