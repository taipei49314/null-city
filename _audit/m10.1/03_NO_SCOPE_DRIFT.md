# No Scope Drift

Reject or defer all of the following during M10.1:

- new scenario content;
- new commands or scoring rules;
- UI redesign;
- auth, database, cloud, multiplayer, hosted leaderboard;
- engine refactor unrelated to the counterexample;
- replacing evidence with test-count claims;
- importing simulation/truth runtime into the live player UI merely to make the badge green.

The objective is an honest, complete public repository—not another milestone.
